# 阶段 4 第三步：投影到直线和子空间——设计说明

## 1. 目标

新建学习笔记：

`summary4/第三步_投影到直线和子空间.md`

笔记承接第二步的正交、标准正交基与正交补，并为第四步的最小二乘和正规方程建立几何基础。

完成学习后，读者应能从“子空间中的最近点”这一问题出发，独立推导投影公式，区分投影与残差所在的空间，并解释投影矩阵的对称性和幂等性。

## 2. 内容边界

本步包含：

- 最近点与残差正交的几何关系；
- 向量投影到一条过原点直线；
- 投影系数与投影向量的区别；
- 使用标准正交基投影到高维子空间；
- 投影矩阵 `P=QQ^T`；
- `P^T=P` 与 `P^2=P` 的含义和证明；
- 补空间投影 `I-P`；
- 投影的唯一性；
- 二维和三维数值例题；
- 本步总结、自测题与答案。

本步不提前展开：

- 一般非标准正交基下的正规方程；
- 最小二乘参数的存在性与唯一性；
- Gram–Schmidt 和 QR 分解；
- 伪逆与 SVD。

这些内容分别留到阶段 4 的后续步骤。

## 3. 讲解结构

采用方案 A：几何直觉优先。

整体学习链条为：

```text
最近点问题
→ 残差为什么必须正交
→ 投影到一条直线
→ 投影系数与投影向量
→ 投影到标准正交基张成的子空间
→ 投影矩阵
→ 补空间投影
→ 唯一性与距离最小证明
→ 完整数值例题
```

预计正文按以下章节组织：

1. 从“无精确命中”进入最近点问题；
2. 投影点、残差与正交条件；
3. 投影到直线的公式推导；
4. 单位方向下的简化公式；
5. 投影系数与投影向量；
6. 为什么投影点是唯一最近点；
7. 投影到具有标准正交基的子空间；
8. 投影矩阵 `P=QQ^T`；
9. 对称性和幂等性；
10. 补空间投影 `I-P`；
11. 与正交直和的联系；
12. 综合计算例题；
13. 常见误区；
14. 知识总结与自测。

## 4. 讲解原则

- 先说明每个符号代表的几何对象，再进行代数推导。
- 每条核心公式都解释“从哪里来”和“算出了什么”。
- 明确区分标量投影系数、向量投影、投影点和残差。
- 使用输入空间与输出空间的语言连接阶段 3，但不提前引入最小二乘推导。
- 例题需要逐步计算，并在结尾检查残差正交性。
- 对称性解释为投影算子的内积结构，幂等性解释为投影后再次投影不再变化。

## 5. 公式与排版规范

- 行内公式使用 `$...$`。
- 独立公式使用 `$$...$$`。
- 多行推导使用 `aligned` 环境。
- 矩阵行末使用 `\\`。
- 向量范数使用 `\|x\|`。
- 实数空间使用 `\mathbb{R}^n`。
- 公式内的中文说明使用 `\text{...}`。
- 避免 `\(...\)`、`\[...\]` 和普通括号代替数学定界符。
- 沿用前两步的普通字母向量风格，不使用影响阅读的粗体向量命令。

## 6. 例题设计

至少安排三个互补例题：

1. 二维向量投影到非单位方向，突出分母 `a^Ta` 的来源；
2. 三维向量投影到具有两列标准正交基的平面，计算 `QQ^Tb`；
3. 使用具体投影矩阵验证 `P^T=P`、`P^2=P`，并计算 `(I-P)b`。

每个例题都需要检查：

- 投影是否属于目标子空间；
- 残差是否属于正交补；
- 投影与残差之和是否还原原向量；
- 距离是否符合最近点结论。

## 7. 验收标准

正式笔记应完整回答《阶段 4 任务》第三步中的五个问题：

1. 为什么最近点对应的残差必须与子空间正交？
2. 投影向量和残差分别属于哪个空间？
3. 为什么投影是唯一最近点？
4. 为什么投影两次与投影一次结果相同？
5. `P` 与 `I-P` 分别投影到哪个空间？

文件还必须满足：

- 内容与阶段 4 后续步骤边界清楚；
- 所有公式能由 VS Code 内置 Markdown 预览正常解析；
- 所有数学环境、花括号和公式定界符成对闭合；
- 没有旧式公式定界符或矩阵单反斜杠；
- 没有未解释的核心符号或跳步推导。
