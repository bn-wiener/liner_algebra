# E6 对称矩阵、谱定理、二次型与正定性

## 11. 一个完整例子

设：

$$
A=
\begin{bmatrix}
2&1\\
1&2
\end{bmatrix}.
$$

特征值与单位特征向量为：

$$
\lambda_1=3,
\qquad
q_1=
\frac{1}{\sqrt2}
\begin{bmatrix}
1\\1
\end{bmatrix},
$$

$$
\lambda_2=1,
\qquad
q_2=
\frac{1}{\sqrt2}
\begin{bmatrix}
1\\-1
\end{bmatrix}.
$$

二者正交：

$$
q_1^Tq_2=0.
$$

构造：

$$
Q=
\frac{1}{\sqrt2}
\begin{bmatrix}
1&1\\
1&-1
\end{bmatrix},
\qquad
\Lambda=
\begin{bmatrix}
3&0\\
0&1
\end{bmatrix}.
$$

由于：

$$
Q^TQ=I,
$$

可验证：

$$
\boxed{A=Q\Lambda Q^T}.
$$

这表示 $A$ 沿 $q_1$ 方向放大 $3$ 倍，沿与之垂直的 $q_2$ 方向保持不变。

## 四、具体数值例子

考虑：

```text
A =
[2  1
 1  2]
```

取：

```text
x =
[x1
 x2]
```

那么：

```text
q(x) = x^T A x
```

先算：

```text
Ax =
[2x1 + x2
 x1 + 2x2]
```

再左乘：

```text
q(x)
=
[x1  x2]
[2x1 + x2
 x1 + 2x2]
```

得到：

```text
q(x)
=
x1(2x1+x2)
+
x2(x1+2x2)
```

展开：

```text
q(x)
=
2x1² + 2x1x2 + 2x2²
```

所以：

```text
A =
[2 1
 1 2]
```

编码的其实就是这个二次函数：

```text
2x1² + 2x1x2 + 2x2²
```

## 八、特征值的正负决定二次型的形状

这一点非常重要。

假设对角化以后：

```text
q(x)
=
λ1 y1² + λ2 y2²
```

### 情况 1：所有 λ > 0

例如：

```text
q(x) = 3y1² + y2²
```

无论 y 指向哪里：

```text
q(x) > 0
```

只要：

```text
x != 0
```

这种称为：

```text
正定二次型
```

对应：

```text
A 正定
```

几何上是一个“碗”：

```text
        ↑
      ╱   ╲
    ╱       ╲
──●────────────
```

或者看等高线：

```text
椭圆
```

---

### 情况 2：所有 λ < 0

例如：

```text
q(x)
=
-3y1² - y2²
```

称为：

```text
负定
```

相当于一个倒扣的碗。

---

### 情况 3：有正有负

例如：

```text
q(x)
=
3y1² - y2²
```

一个方向往上：

```text
+3y1²
```

一个方向往下：

```text
-y2²
```

所以形成：

```text
马鞍面
```

称为：

```text
不定二次型
```

这也是为什么优化问题里 Hessian 的特征值这么重要。
