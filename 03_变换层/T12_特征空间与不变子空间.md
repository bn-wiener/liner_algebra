# T12 特征空间与不变子空间

> **学习定位**：从单个特殊方向上升到“整个子空间经过变换后仍留在自身内部”的结构。

## 本节主线

对给定特征值 $\lambda$：

$$
E_\lambda=\operatorname{Null}(A-\lambda I).
$$

它是所有对应特征向量再加零向量构成的子空间。

## 五、特征空间是什么

如果：

```text
Av = λv
```

移项：

```text
Av - λv = 0
```

写成矩阵：

```text
(A - λI)v = 0
```

所以对于一个固定特征值 λ：

```text
E_λ = Null(A - λI)
```

这就是 λ 对应的 **特征空间**。

因此：

```text
特征空间 = 满足 Av = λv 的所有向量组成的空间
```

更准确地说：

```text
E_λ = {v | Av = λv}
```

这里面包括零向量。

但：

```text
特征向量 = E_λ 中所有非零向量
```

## 六、为什么特征向量不是一个，而通常是一整片空间

假设：

```text
A =
[2 0
 0 3]
```

对于：

```text
λ = 2
```

有：

```text
(A - 2I)
=
[0 0
 0 1]
```

解：

```text
(A - 2I)v = 0
```

得到：

```text
v =
[t
 0]
```

所以特征空间：

```text
E_2 =
span {
[1
 0]
}
```

并不是只有：

```text
[1
 0]
```

而是：

```text
[1,0]
[2,0]
[-5,0]
[0.3,0]
...
```

所有 x 轴上的非零向量都是 λ=2 的特征向量。

所以应该区分：

```text
特征向量：某个具体向量

特征空间：所有属于同一个特征方向结构的向量集合
```

---


## 七、特征空间真正描述的是“不变子空间”

特征空间最重要的几何性质其实是：

```text
A(E_λ) ⊆ E_λ
```

也就是说：

> 一个向量只要在某个特征空间里，经过 A 之后仍然留在这个特征空间里。

例如：

```text
E_2 = x轴
```

那么：

```text
A
```

不会把 x 轴上的向量转到 y 轴或者其它方向。

它只会：

```text
拉伸
压缩
反向
或者压到0
```

因此可以把特征空间理解成：

> A 自己能够保持不变的“内部方向子空间”。

---


## 二十六、输入空间是不是由特征空间组成

之前你提出过一个非常关键的问题：

> 方阵的普通输入向量是不是都由特征向量线性组合得到？

答案是：

```text
不一定。
```

只有当 A 可以对角化时：

```text
R^n =
E_λ1 ⊕ E_λ2 ⊕ ... ⊕ E_λk
```

也就是：

> 各个特征空间的直和能够覆盖整个输入空间。

这时候任意：

```text
x
```

都可以唯一写成：

```text
x = x1 + x2 + ... + xk
```

其中：

```text
xi ∈ E_λi
```

于是：

```text
Ax
=
λ1x1 + λ2x2 + ... + λkxk
```

这就是最完美的“特征方向分解”。

但如果矩阵不可对角化：

```text
特征空间无法张成整个 R^n
```

就还存在一些普通向量，不能仅仅通过普通特征向量完整表示。

---


## 二十八、行空间 + 零空间与特征空间不是同一种分解

这里也是项目讨论中非常容易混淆的一点。

对于：

```text
A : R^n -> R^m
```

输入空间有经典正交分解：

```text
R^n =
Row(A) ⊕ Null(A)
```

更严格地说：

```text
Row(A) = Null(A)^⊥
```

这套分解关注的是：

```text
哪些输入方向 A 能检测
哪些输入方向 A 完全检测不到
```

而特征空间分解：

```text
R^n =
E_λ1 ⊕ E_λ2 ⊕ ...
```

研究的是：

```text
A 在哪些方向上只进行缩放
```

因此它们回答的是不同的问题。

---

## 本节统一

特征空间是一类非常特殊的不变子空间，但不能把所有不变子空间都简单等同于某个单一特征空间，也不能默认整个输入空间一定由特征空间直和组成。是否能做到这一点正是对角化要回答的问题。

## 下一步为什么自然出现

在研究特征空间之前，首先必须系统找到允许出现的 $\lambda$；这需要特征方程。
