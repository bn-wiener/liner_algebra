# 综合练习 1：方程、空间与变换

给定：

$$
A=
\begin{bmatrix}
1&2&1\\
2&4&2\\
0&1&1
\end{bmatrix},
\qquad
\boldsymbol{b}=
\begin{bmatrix}
1\\2\\1
\end{bmatrix}.
$$

请尽量不查正文完成以下问题。

## 题 1：基础层

1. 对增广矩阵 $[A\mid\boldsymbol{b}]$ 做高斯消元并写出 RREF。
2. 指出主变量与自由变量。
3. 写出 $A\boldsymbol{x}=\boldsymbol{b}$ 的全部解。
4. 写成“特解 + 齐次解”的参数向量形式。

## 题 2：空间层

1. 求 $\operatorname{rank}(A)$ 和 $\operatorname{nullity}(A)$。
2. 求 $\operatorname{Col}(A)$ 的一组基。
3. 求 $\operatorname{Null}(A)$ 的一组基。
4. 求 $\operatorname{Row}(A)$ 的一组基。
5. 求 $\operatorname{Null}(A^{\mathsf T})$ 的一组基。
6. 分别指出四个基本子空间位于哪个环境空间。

## 题 3：跨层解释

用三种语言解释下面四个事实：

1. 方程有解；
2. 解不唯一；
3. rank 为 $2$；
4. 存在一个非零输入方向经过 $A$ 后变成零。

## 题 4：变换层

令：

$$
T(\boldsymbol{x})=A\boldsymbol{x}.
$$

1. 求 $T(\boldsymbol{e}_1),T(\boldsymbol{e}_2),T(\boldsymbol{e}_3)$。
2. 写出 $\ker T$ 与 $\operatorname{Im}T$。
3. 这个变换是否可逆？为什么？
4. 从输入维数、输出维数、rank、kernel 四个角度解释信息损失。

## 题 5：判断

判断正误并说明理由：

1. RREF 的主元列可以直接作为原矩阵列空间的一组基。
2. RREF 的非零行可以作为原矩阵行空间的一组基。
3. 自由变量个数一定等于零空间维数。
4. 如果 $\operatorname{Null}(A)$ 含非零向量，则 $A\boldsymbol{x}=\boldsymbol{b}$ 对某个可达 $\boldsymbol{b}$ 不可能有唯一解。
5. rank 为 $2$ 表示这个变换保留了两个独立方向。
