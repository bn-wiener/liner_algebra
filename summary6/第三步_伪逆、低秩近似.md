可以把 **SVD、伪逆、低秩近似** 看成同一个故事的三个阶段：

[
\boxed{
A=U\Sigma V^T
}
]

告诉我们：

> 一个任意线性变换 (A)，本质上都是
> **“找到输入空间中真正有效的方向 → 分别缩放 → 放到输出空间对应方向”**。

然后：

* **SVD**：把这个结构拆出来；
* **伪逆 (A^+)**：把这些“有效方向上的缩放”反过来；
* **低秩近似 (A_k)**：只保留最重要的几个方向。

所以这三个知识其实是一条完整主线：

[
\boxed{
\text{理解 }A
\rightarrow
\text{反解 }Ax=b
\rightarrow
\text{压缩 }A
}
]

---

# 一、先统一背景：矩阵 (A) 到底是什么

设

[
A\in\mathbb R^{m\times n}.
]

那么它表示一个线性变换：

[
T:\mathbb R^n\rightarrow\mathbb R^m,
]

即

[
x\mapsto Ax.
]

所以一定要区分两个空间：

```text
输入空间 R^n
    ↓
    A
    ↓
输出空间 R^m
```

例如：

[
A\in\mathbb R^{3\times 2}
]

表示：

[
\mathbb R^2\rightarrow\mathbb R^3.
]

这时候：

* (x) 在二维输入空间；
* (Ax) 在三维输出空间。

---

# 二、SVD：把任意线性变换拆成最简单的动作

## 1. SVD 公式

任意矩阵：

[
A\in\mathbb R^{m\times n}
]

都可以分解为：

[
\boxed{
A=U\Sigma V^T
}
]

其中：

[
U\in\mathbb R^{m\times m},
]

[
V\in\mathbb R^{n\times n},
]

都是正交矩阵：

[
U^TU=I,
\qquad
V^TV=I.
]

而：

[
\Sigma\in\mathbb R^{m\times n}
]

是“矩形对角矩阵”。

例如：

[
\Sigma=
\begin{bmatrix}
\sigma_1&0\
0&\sigma_2\
0&0
\end{bmatrix}.
]

其中：

[
\sigma_1\geq\sigma_2\geq\cdots\geq0
]

称为奇异值。

---

# 三、SVD 最重要的几何意义

不要先把：

[
A=U\Sigma V^T
]

理解成三个矩阵相乘。

应该理解成三个动作。

对于：

[
y=Ax
]

有：

[
y
=

U\Sigma V^Tx.
]

即：

[
x
\xrightarrow{V^T}
V^Tx
\xrightarrow{\Sigma}
\Sigma V^Tx
\xrightarrow{U}
U\Sigma V^Tx.
]

---

## 第一步：(V^T) —— 换到最适合 (A) 的输入基

(V) 的列：

[
v_1,v_2,\cdots,v_n
]

构成输入空间 (\mathbb R^n) 的一组标准正交基。

所以任何：

[
x\in\mathbb R^n
]

都可以表示：

[
x=
(v_1^Tx)v_1+
(v_2^Tx)v_2+\cdots.
]

于是：

[
V^Tx=
\begin{bmatrix}
v_1^Tx\
v_2^Tx\
\vdots
\end{bmatrix}.
]

它表示：

> (x) 在 (V) 这组输入基下的坐标。

---

## 第二步：(\Sigma) —— 每个方向独立缩放

假设：

[
V^Tx=
\begin{bmatrix}
c_1\
c_2\
\vdots
\end{bmatrix}.
]

那么：

[
\Sigma V^Tx
===========

\begin{bmatrix}
\sigma_1c_1\
\sigma_2c_2\
\vdots
\end{bmatrix}.
]

也就是：

```text
v1方向分量 → 放大 σ1 倍
v2方向分量 → 放大 σ2 倍
...
```

但是这里要特别注意一个很容易误解的地方：

> (\Sigma V^Tx) 已经不是“在原来的 (v_i) 几何方向上伸缩后的向量”。

它是：

> **输出空间 (U) 基下的坐标。**

这点非常重要。

---

# 四、为什么 (\Sigma) 后面可以直接乘 (U)

这是理解 SVD 的核心。

有：

[
Av_i=\sigma_i u_i.
]

所以：

[
A
]

不是把：

[
v_i\rightarrow \sigma_i v_i,
]

而是：

[
\boxed{
v_i\rightarrow\sigma_i u_i
}
]

其中：

* (v_i)：输入空间中的方向；
* (u_i)：输出空间中的方向。

因此如果：

[
x=c_1v_1+c_2v_2,
]

那么：

[
Ax
==

c_1Av_1+c_2Av_2
]

所以：

[
Ax
==

c_1\sigma_1u_1
+
c_2\sigma_2u_2.
]

因此：

[
\Sigma V^Tx
===========

\begin{bmatrix}
\sigma_1c_1\
\sigma_2c_2
\end{bmatrix}
]

表示的是：

> 输出空间的 (u_1,u_2) 基下的坐标。

最后乘：

[
U
]

就是：

[
U
\begin{bmatrix}
\sigma_1c_1\
\sigma_2c_2
\end{bmatrix}
=============

\sigma_1c_1u_1+\sigma_2c_2u_2.
]

---

# 五、所以 SVD 真正应该写成什么

比：

[
A=U\Sigma V^T
]

更适合理解的公式其实是：

[
\boxed{
Ax
==

\sum_{i=1}^r
\sigma_i
u_i
(v_i^Tx)
}
]

这里：

[
r=\operatorname{rank}(A).
]

逐项理解：

[
v_i^Tx
]

回答：

> 输入 (x) 中有多少 (v_i) 成分？

然后：

[
\sigma_i(v_i^Tx)
]

回答：

> 这个成分经过 (A) 后应该变多大？

最后：

[
\sigma_i(v_i^Tx)u_i
]

回答：

> 把这个成分放到输出方向 (u_i) 上。

因此：

[
\boxed{
A
=

\sum_{i=1}^r
\sigma_i u_i v_i^T
}
]

这其实比矩阵乘法更能揭示 SVD 的本质。

---

# 六、每一个 (\sigma_i u_i v_i^T) 都是什么

考虑：

[
A_i=\sigma_i u_i v_i^T.
]

作用于 (x)：

[
A_ix
====

\sigma_i u_i v_i^Tx.
]

分三步：

[
x
\xrightarrow{v_i^T}
v_i^Tx
]

得到一个标量；

然后：

[
v_i^Tx
\xrightarrow{\times\sigma_i}
\sigma_i v_i^Tx
]

最后：

[
\sigma_i v_i^Tx
\xrightarrow{\times u_i}
\sigma_i(v_i^Tx)u_i.
]

所以：

[
\boxed{
\sigma_i u_i v_i^T
}
]

就是一个 **秩 1 线性变换**：

> 只观察输入空间中的一个方向 (v_i)，
> 然后把这个成分投射到输出空间中的一个方向 (u_i)。

于是整个 (A) 就是多个秩 1 变换的叠加：

[
\boxed{
A=
\sigma_1u_1v_1^T+
\sigma_2u_2v_2^T+
\cdots+
\sigma_ru_rv_r^T
}
]

这正是后面“低秩近似”的基础。

---

# 七、SVD 与秩

如果：

[
\sigma_1\geq
\sigma_2\geq
\cdots\geq
\sigma_r>0
]

而后面：

[
\sigma_{r+1}=\cdots=0,
]

那么：

[
\boxed{
\operatorname{rank}(A)=r
}
]

为什么？

因为：

[
Av_i=\sigma_i u_i.
]

如果：

[
\sigma_i>0,
]

那么：

[
Av_i\neq0.
]

说明：

[
v_i
]

这个输入方向能够产生输出。

但是如果：

[
\sigma_i=0,
]

则：

[
Av_i=0.
]

这个方向被 (A) 完全压扁。

---

# 八、这时四个基本子空间就全部出现了

设：

[
A\in\mathbb R^{m\times n},
\qquad
\operatorname{rank}(A)=r.
]

SVD：

[
A=U\Sigma V^T.
]

那么：

## 输入空间

[
\mathbb R^n
]

分解成：

[
\boxed{
\mathbb R^n
===========

\operatorname{Row}(A)
\oplus
N(A)
}
]

其中：

[
\operatorname{Row}(A)
=====================

\operatorname{span}
{v_1,\ldots,v_r},
]

而：

[
N(A)
====

\operatorname{span}
{v_{r+1},\ldots,v_n}.
]

---

## 输出空间

[
\mathbb R^m
]

分解成：

[
\boxed{
\mathbb R^m
===========

\operatorname{Col}(A)
\oplus
N(A^T)
}
]

其中：

[
\operatorname{Col}(A)
=====================

\operatorname{span}
{u_1,\ldots,u_r},
]

而：

[
N(A^T)
======

\operatorname{span}
{u_{r+1},\ldots,u_m}.
]

因此整个 SVD 可以画成：

```text
输入空间 R^n

span(v1,...,vr)                N(A)
有效输入空间                  无效输入空间
      │                           │
      │ σ1,...,σr                │ σ=0
      ↓                           ↓
span(u1,...,ur)                  0

列空间 Col(A)

输出空间 R^m 中剩余部分：
N(A^T)
```

---

# 九、现在进入伪逆：为什么需要 (A^+)

先从普通逆矩阵开始。

如果：

[
A\in\mathbb R^{n\times n}
]

且可逆，那么：

[
Ax=b
]

有：

[
x=A^{-1}b.
]

但现实中有大量矩阵：

* 不是方阵；
* 不满秩；
* 方程无解；
* 方程有无穷多解。

例如：

[
A\in\mathbb R^{3\times2}.
]

它根本没有普通意义上的：

[
A^{-1}.
]

但我们仍然希望回答：

[
\boxed{
Ax\approx b
}
]

到底应该取哪个 (x)？

这就出现了：

[
\boxed{
A^+
}
]

Moore-Penrose 伪逆。

---

# 十、伪逆最简单的理解：把 SVD 倒过来

有：

[
A=U\Sigma V^T.
]

(A) 做的是：

[
v_i
\xrightarrow{A}
\sigma_i u_i.
]

那么如果希望反过来，自然应该：

[
u_i
\rightarrow
\frac{1}{\sigma_i}v_i.
]

因此：

[
\boxed{
A^+
===

V\Sigma^+U^T
}
]

其中：

[
\Sigma^+
]

就是：

> 把非零奇异值取倒数，再转置矩阵形状。

---

# 十一、具体看 (\Sigma^+)

例如：

[
\Sigma=
\begin{bmatrix}
5&0\
0&2\
0&0
\end{bmatrix}.
]

那么：

[
\Sigma^+
========

\begin{bmatrix}
\frac15&0&0\
0&\frac12&0
\end{bmatrix}.
]

注意：

[
0
]

不能取倒数。

所以定义：

[
\sigma_i^+
==========

\begin{cases}
\dfrac1{\sigma_i},&\sigma_i>0,\
0,&\sigma_i=0.
\end{cases}
]

因此：

[
\boxed{
A^+
===

\sum_{i=1}^r
\frac1{\sigma_i}
v_i u_i^T
}
]

与：

[
A
=

\sum_{i=1}^r
\sigma_i u_i v_i^T
]

完美对称。

---

# 十二、伪逆的几何过程

求：

[
x=A^+b.
]

代入：

[
x=V\Sigma^+U^Tb.
]

分三步。

---

## 第一步：(U^Tb)

把：

[
b
]

分解到输出空间的 (U) 基：

[
U^Tb=
\begin{bmatrix}
u_1^Tb\
u_2^Tb\
\vdots
\end{bmatrix}.
]

也就是问：

```text
b 在 u1 上多少？
b 在 u2 上多少？
...
```

---

## 第二步：(\Sigma^+)

对可逆方向执行：

[
u_i
\rightarrow
\frac1{\sigma_i}v_i.
]

所以：

[
\frac{u_i^Tb}{\sigma_i}.
]

---

## 第三步：(V)

把这些输入坐标重新组合：

[
\boxed{
A^+b
====

\sum_{i=1}^r
\frac{u_i^Tb}{\sigma_i}v_i
}
]

所以伪逆的本质是：

> 在 (A) 能够传递信息的方向上逆变换；
> 对已经被 (A) 消灭的信息，不试图恢复。

---

# 十三、为什么伪逆不是普通意义的逆

假如：

[
Av_3=0.
]

那么：

[
v_3
]

方向的信息经过 (A) 以后彻底消失。

比如：

[
x_1=v_1,
]

和：

[
x_2=v_1+100v_3.
]

因为：

[
Av_3=0,
]

所以：

[
Ax_2
====

# Av_1+100Av_3

Av_1.
]

因此：

[
Ax_1=Ax_2.
]

仅仅看到输出以后，不可能知道原输入到底是：

[
v_1
]

还是：

[
v_1+100v_3.
]

所以这部分信息从数学上已经丢失。

伪逆不会“猜”。

它直接选择：

[
v_3
]

分量为零。

这就是为什么伪逆给出：

[
\boxed{
\text{最小范数解}
}
]

---

# 十四、伪逆解决第一种问题：方程无解

考虑：

[
Ax=b.
]

如果：

[
b\notin\operatorname{Col}(A),
]

那么没有任何：

[
x
]

可以满足：

[
Ax=b.
]

怎么办？

寻找：

[
\min_x|Ax-b|_2.
]

这就是最小二乘：

[
\boxed{
x^*=A^+b
}
]

---

# 十五、为什么它是最小二乘

因为输出空间：

[
\mathbb R^m
]

可以分解为：

[
\operatorname{Col}(A)
\oplus N(A^T).
]

所以：

[
b=b_{\parallel}+b_{\perp},
]

其中：

[
b_{\parallel}\in\operatorname{Col}(A),
]

[
b_{\perp}\in N(A^T).
]

但是无论取什么 (x)：

[
Ax\in\operatorname{Col}(A).
]

所以永远不可能产生：

[
b_{\perp}.
]

最好的办法就是：

[
Ax=b_{\parallel}.
]

也就是把 (b) 正交投影到：

[
\operatorname{Col}(A).
]

而：

[
\boxed{
AA^+b
}
]

正是这个投影。

因此：

[
\boxed{
AA^+
}
]

是输出空间到列空间的正交投影矩阵：

[
\boxed{
AA^+=P_{\operatorname{Col}(A)}
}
]

---

# 十六、伪逆解决第二种问题：无穷多解

如果：

[
Ax=b
]

有无穷多解。

那么：

[
x=x_0+z,
]

其中：

[
z\in N(A).
]

因为：

[
Az=0.
]

所以：

[
A(x_0+z)=Ax_0=b.
]

也就是说：

> 零空间中的分量完全不影响输出。

伪逆选择：

[
z=0.
]

因此：

[
x^*=A^+b
]

是所有解中：

[
\boxed{
|x|_2
}
]

最小的那个。

---

# 十七、(A^+A) 又是什么

前面：

[
AA^+
]

是：

[
\mathbb R^m
]

中的列空间投影。

而：

[
A^+A
]

作用在输入空间：

[
\mathbb R^n.
]

有：

[
\boxed{
A^+A
====

P_{\operatorname{Row}(A)}
}
]

也就是：

> 把输入 (x) 投影到真正对 (Ax) 有贡献的输入方向。

因为：

[
\operatorname{Row}(A)
=====================

N(A)^\perp.
]

---

# 十八、这是非常漂亮的一组关系

[
\boxed{
AA^+
====

P_{\operatorname{Col}(A)}
}
]

[
\boxed{
A^+A
====

P_{\operatorname{Row}(A)}
}
]

因此 SVD + 伪逆把四个子空间直接连接起来了：

```text
输入空间
R^n
│
├── Row(A) ─── A ───→ Col(A)
│
└── N(A)  ─── A ───→ 0
```

反过来：

```text
输出空间
R^m
│
├── Col(A) ── A+ ──→ Row(A)
│
└── N(A^T) ─ A+ ──→ 0
```

这张图非常重要。

---

# 十九、一个完整数值例子

考虑：

[
A=
\begin{bmatrix}
3&0\
0&1\
0&0
\end{bmatrix}.
]

它实际上已经是 SVD 形式：

[
U=I_3,
]

[
V=I_2,
]

[
\Sigma=
\begin{bmatrix}
3&0\
0&1\
0&0
\end{bmatrix}.
]

奇异值：

[
\sigma_1=3,
\qquad
\sigma_2=1.
]

---

## 输入

设：

[
x=
\begin{bmatrix}
2\
4
\end{bmatrix}.
]

那么：

[
Ax
==

\begin{bmatrix}
6\
4\
0
\end{bmatrix}.
]

几何意义：

```text
输入 x1 方向 → 放大3倍 → 输出u1
输入 x2 方向 → 放大1倍 → 输出u2
```

---

# 二十、用伪逆反解

有：

[
A^+
===

\begin{bmatrix}
1/3&0&0\
0&1&0
\end{bmatrix}.
]

假设：

[
b=
\begin{bmatrix}
6\
4\
5
\end{bmatrix}.
]

注意：

[
b\notin\operatorname{Col}(A),
]

因为：

[
\operatorname{Col}(A)
=====================

\left{
\begin{bmatrix}
a\

0
\end{bmatrix}
\right}.
]

第三个分量永远不可能由 (A) 产生。

于是：

[
x^*
===

A^+b
]

得到：

[
x^*
===

\begin{bmatrix}
1/3&0&0\
0&1&0
\end{bmatrix}
\begin{bmatrix}
6\

\end{bmatrix}
=============

\begin{bmatrix}

\end{bmatrix}.
]

再计算：

[
Ax^*
====

\begin{bmatrix}

\end{bmatrix}.
]

也就是：

[
b
=

\begin{bmatrix}
6\

\end{bmatrix}
]

被投影成：

[
\begin{bmatrix}
6\
4\

\end{bmatrix}.
]

残差：

r=

======

\begin{bmatrix}

\end{bmatrix}.

且：

]

这就是最小二乘的几何本质。

# 二十一、现在进入低秩近似

前面有：

[
\boxed{
A=
\sum_{i=1}^r
\sigma_i u_i v_i^T
}
]

这说明：

> 一个秩 (r) 矩阵，可以看成 (r) 个秩 1 模式叠加。

而且：

[
\sigma_1\geq\sigma_2\geq\cdots\geq\sigma_r.
]

奇异值大小表示：

> 对应模式的重要程度 / 强度。

所以如果：

[
\sigma_1,\sigma_2
]

很大，而：

[
\sigma_3,\ldots,\sigma_r
]

非常小，那么可以只保留前两个：

[
\boxed{
A_2
===

\sigma_1u_1v_1^T
+
\sigma_2u_2v_2^T
}
]

这就是秩 2 近似。

---

# 二十二、低秩近似的 SVD 表达

完整 SVD：

[
A=U\Sigma V^T.
]

只取前 (k) 个：

[
U_k=
\begin{bmatrix}
u_1&\cdots&u_k
\end{bmatrix},
]

[
V_k=
\begin{bmatrix}
v_1&\cdots&v_k
\end{bmatrix},
]

[
\Sigma_k=
\begin{bmatrix}
\sigma_1&&\
&\ddots&\
&&\sigma_k
\end{bmatrix}.
]

于是：

[
\boxed{
A_k
===

U_k\Sigma_kV_k^T
}
]

满足：

[
\operatorname{rank}(A_k)\leq k.
]

---

# 二十三、为什么 SVD 截断是“最佳低秩近似”

这是 SVD 最强大的结论之一：

## Eckart–Young 定理

在所有秩不超过 (k) 的矩阵中：

[
\boxed{
A_k=U_k\Sigma_kV_k^T
}
]

是距离原矩阵 (A) 最近的矩阵。

如果用谱范数：

[
\boxed{
|A-A_k|_2
=========

\sigma_{k+1}
}
]

如果用 Frobenius 范数：

[
\boxed{
|A-A_k|_F^2
===========

\sum_{i=k+1}^r\sigma_i^2
}
]

所以：

> 丢掉哪些模式造成的误差最小？

答案就是：

[
\boxed{
丢掉最小奇异值对应的模式
}
]

---

# 二十四、一个非常直观的例子

假设：

[
A
=

10u_1v_1^T
+
3u_2v_2^T
+
0.1u_3v_3^T.
]

也就是说：

[
\sigma_1=10,
]

[
\sigma_2=3,
]

[
\sigma_3=0.1.
]

那么第三种模式非常弱。

如果做 rank-2 近似：

[
A_2
===

10u_1v_1^T
+
3u_2v_2^T.
]

舍弃：

[
0.1u_3v_3^T.
]

此时：

[
|A-A_2|_2=0.1.
]

所以损失很小。

---

# 二十五、从“信息”角度理解低秩

假设矩阵是一张图片。

例如：

[
A\in\mathbb R^{1000\times1000}.
]

原始需要存：

[
10^6
]

个数字。

如果：

[
A\approx U_k\Sigma_kV_k^T
]

且：

[
k=20,
]

那么只需要：

[
1000\times20
+
20
+
1000\times20
]

大约：

[
40020
]

个数字。

而不是：

[
1,000,000.
]

因此：

[
\boxed{
低秩
\approx
数据其实只由少数潜在方向控制
}
]

---

# 二十六、SVD 为什么能做降噪

假设真实数据：

[
A_{\text{true}}
]

本来只有几个主要模式。

但加入噪声：

[
A
=

A_{\text{true}}
+
E.
]

通常：

* 主要结构对应较大奇异值；
* 随机噪声更多分散到较小奇异值方向。

所以：

[
A
=

\sum_i\sigma_i u_i v_i^T
]

以后，只保留前 (k) 个：

[
A_k
===

\sum_{i=1}^k\sigma_i u_i v_i^T.
]

等价于：

> 保留主要结构，抑制弱模式。

于是低秩近似同时可以理解成：

[
\boxed{
压缩 + 降噪 + 特征提取
}
]

---

# 二十七、现在把伪逆和低秩近似联系起来

这个关系特别重要。

伪逆：

[
A^+
===

\sum_{i=1}^r
\frac1{\sigma_i}
v_i u_i^T.
]

注意：

[
\boxed{
\frac1{\sigma_i}
}
]

这意味着：

> 奇异值越小，伪逆反而放大得越厉害。

例如：

[
\sigma_1=10,
]

[
\sigma_2=1,
]

[
\sigma_3=0.001.
]

那么伪逆中的系数：

[
0.1,\quad1,\quad1000.
]

所以第三个方向会被放大：

[
1000
]

倍。

---

# 二十八、这就是病态问题的来源

如果：

[
b
=

Ax+\epsilon
]

其中 (\epsilon) 是很小的噪声。

伪逆：

[
x^*
===

A^+b.
]

展开：

[
x^*
===

\sum_i
\frac{u_i^Tb}{\sigma_i}v_i.
]

假设某个方向：

[
u_i^T\epsilon=0.001,
]

而：

[
\sigma_i=10^{-6}.
]

那么：

[
\frac{0.001}{10^{-6}}
=====================

1000.

]

一个非常小的观测噪声，被放大成巨大的输入误差。

所以：

[
\boxed{
小奇异值
\Longrightarrow
逆问题不稳定
}
]

---

# 二十九、于是低秩近似和伪逆第一次真正合流

既然小奇异值会导致：

[
\frac1{\sigma_i}
]

爆炸，那么一个自然办法就是：

> 特别小的奇异值干脆不要反演。

即：

[
A
\approx
A_k.
]

然后：

[
x_k
===

A_k^+b.
]

于是：

[
\boxed{
x_k
===

\sum_{i=1}^k
\frac{u_i^Tb}{\sigma_i}v_i
}
]

这叫：

[
\boxed{
\text{Truncated SVD, TSVD}
}
]

截断 SVD。

---

# 三十、TSVD 的本质

完整伪逆：

[
A^+b
====

\sum_{i=1}^r
\frac{u_i^Tb}{\sigma_i}v_i.
]

TSVD：

[
A_k^+b
======

\sum_{i=1}^k
\frac{u_i^Tb}{\sigma_i}v_i.
]

所以它相当于说：

```text
大奇异值方向：
相信它，反演。

小奇异值方向：
太不可靠，不反演。
```

因此：

[
\boxed{
低秩近似其实也是一种正则化
}
]

---

# 三十一、条件数也可以用 SVD 理解

如果 (A) 满秩：

[
\kappa_2(A)
===========

# \frac{\sigma_{\max}}{\sigma_{\min}}

\frac{\sigma_1}{\sigma_r}.
]

如果：

[
\sigma_r
]

特别小，那么：

[
\kappa(A)
]

非常大。

说明：

> 某些输入方向经过 (A) 被压得非常小，因此逆变换必须重新极度放大。

所以病态矩阵的几何本质是：

[
\boxed{
A
\text{ 把某些方向压得几乎扁平}
}
]

这时求逆一定不稳定。

---

# 三十二、一个二维椭圆理解所有问题

假设：

[
A
]

把单位圆：

[
|x|=1
]

变成一个椭圆。

SVD 告诉你：

[
v_1,v_2
]

是输入圆上的特殊方向。

经过：

[
A
]

以后：

[
v_1\rightarrow\sigma_1u_1,
]

[
v_2\rightarrow\sigma_2u_2.
]

于是单位圆变成椭圆：

* 主轴方向：(u_1,u_2)；
* 主轴长度：(\sigma_1,\sigma_2)。

---

如果：

[
\sigma_1=10,
\qquad
\sigma_2=0.001,
]

那么椭圆极度扁：

```text
──────────────
```

几乎变成一条线。

此时从输出反推输入：

* 沿 (u_1) 比较稳定；
* 沿 (u_2) 极不稳定。

因为：

[
\frac1{\sigma_2}
================

1000.

]

---

如果直接忽略第二个方向：

[
A_1
===

\sigma_1u_1v_1^T,
]

这就是 rank-1 近似。

所以：

```text
SVD：
发现椭圆主轴

伪逆：
沿主轴反向缩放

低秩近似：
舍弃太短的主轴
```

---

# 三十三、再从 (Ax=b) 的角度统一起来

这是最重要的一层。

我们一直在研究：

[
\boxed{
Ax=b
}
]

SVD：

[
A=U\Sigma V^T.
]

代入：

[
U\Sigma V^Tx=b.
]

左乘：

[
U^T
]

得到：

[
\Sigma V^Tx=U^Tb.
]

定义：

[
z=V^Tx,
]

[
c=U^Tb.
]

于是复杂方程：

[
Ax=b
]

被变成：

[
\boxed{
\Sigma z=c
}
]

这其实就是一组独立的一维方程：

[
\sigma_i z_i=c_i.
]

所以：

[
z_i=\frac{c_i}{\sigma_i}.
]

即：

[
z_i
===

\frac{u_i^Tb}{\sigma_i}.
]

最后：

[
x=Vz.
]

得到：

[
\boxed{
x
=

\sum_i
\frac{u_i^Tb}{\sigma_i}v_i
}
]

这就是伪逆公式。

所以伪逆并不是一个凭空定义的东西。

它其实就是：

> 用 SVD 把 (Ax=b) 化成一堆互不干扰的一维方程，然后逐个求解。

---

# 三十四、如果 (\sigma_i=0) 怎么办

对于：

[
\sigma_i z_i=c_i,
]

如果：

[
\sigma_i=0,
]

则变成：

[
0\cdot z_i=c_i.
]

有两种情况。

---

### 情况 1

[
c_i\neq0.
]

那么：

[
0=c_i
]

不可能。

说明：

[
b
]

在这个方向有分量，但是：

[
A
]

永远不能产生这个方向。

这就是：

[
b\notin\operatorname{Col}(A).
]

最小二乘把这个分量丢掉。

---

### 情况 2

[
c_i=0.
]

则：

[
0\cdot z_i=0.
]

任何：

[
z_i
]

都可以。

这就是：

[
N(A)
]

产生的自由度。

伪逆选择：

[
z_i=0.
]

于是得到最小范数解。

---

# 三十五、所以伪逆同时处理了“无解”和“多解”

这一点非常漂亮。

对于：

[
Ax=b
]

伪逆：

[
x^*=A^+b
]

统一处理：

### 唯一解

直接得到唯一解。

### 无解

得到：

[
\min_x|Ax-b|_2
]

的最小二乘解。

### 无穷多解

得到其中：

[
\min|x|_2
]

的最小范数解。

更完整地说：

[
\boxed{
A^+b
====

\arg\min_{\substack{x\
|Ax-b|\text{ 最小}}}
|x|
}
]

也就是：

> 先让残差最小；
> 如果有多个残差一样小的解，再选择范数最小的。

# 三十六、SVD、PCA、低秩近似是什么关系

这又是一条重要联系。

如果数据矩阵：

[
X
]

做 SVD：

[
X=U\Sigma V^T,
]

那么：

[
X^TX
====

V\Sigma^2V^T.
]

所以：

[
v_i
]

是：

[
X^TX
]

的特征向量。

对应特征值：

[
\lambda_i=\sigma_i^2.
]

如果 (X) 已经中心化，那么 PCA 就是在寻找：

[
v_1,v_2,\ldots
]

这些最大方差方向。

所以：

[
\boxed{
PCA
\approx
对中心化数据矩阵做截断 SVD
}
]

本质都是：

> 找出最重要的低维子空间。

---

# 三十七、SVD、特征分解、低秩近似的区别

特征分解：

[
A=P\Lambda P^{-1}
]

研究的是：

[
Av_i=\lambda_i v_i.
]

输入和输出必须在同一个空间，因为：

[
v_i\rightarrow v_i.
]

所以通常要求：

[
A\in\mathbb R^{n\times n}.
]

而 SVD：

[
Av_i=\sigma_i u_i.
]

允许：

[
v_i
]

和：

[
u_i
]

属于不同空间。

因此：

[
A\in\mathbb R^{m\times n}
]

也完全没问题。

这也是为什么 SVD 比特征分解更适合研究一般线性变换。

---

# 三十八、为什么 (v_i) 和 (u_i) 能从 (A^TA)、(AA^T) 得到

由：

[
Av_i=\sigma_i u_i.
]

左乘：

[
A^T
]

得到：

[
A^TAv_i
=======

\sigma_iA^Tu_i.
]

又有：

[
A^Tu_i=\sigma_i v_i.
]

所以：

[
A^TAv_i
=======

\sigma_i^2v_i.
]

因此：

[
\boxed{
A^TAv_i=\sigma_i^2v_i
}
]

同理：

[
\boxed{
AA^Tu_i=\sigma_i^2u_i
}
]

所以：

* (V)：(A^TA) 的特征向量；
* (U)：(AA^T) 的特征向量。

而不是：

> (u_i,v_i) 都属于 (A^TA) 的空间。

维度上就能看出来：

[
A\in\mathbb R^{m\times n},
]

则：

[
A^TA\in\mathbb R^{n\times n},
]

作用在：

[
\mathbb R^n
]

输入空间；

而：

[
AA^T\in\mathbb R^{m\times m},
]

作用在：

[
\mathbb R^m
]

输出空间。

---

# 三十九、最终统一：三个知识其实是同一套坐标系统

现在可以把整个逻辑压缩成：

[
\boxed{
A=U\Sigma V^T
}
]

### SVD

回答：

> (A) 在哪些输入方向 (v_i) 上工作？

以及：

> 每个方向被放大多少 (\sigma_i)？

以及：

> 最后对应输出哪个方向 (u_i)？

---

### 伪逆

[
\boxed{
A^+=V\Sigma^+U^T
}
]

回答：

> 如果知道输出 (b)，如何沿这些有效方向反推输入？

即：

[
u_i
\rightarrow
\frac1{\sigma_i}v_i.
]

---

### 低秩近似

[
\boxed{
A_k
===

U_k\Sigma_kV_k^T
}
]

回答：

> 如果只保留最重要的 (k) 个输入-输出模式，(A) 会变成什么？

---

# 四十、你应该建立的统一心智模型

最终不要分别记忆：

```text
SVD
伪逆
低秩近似
最小二乘
四个子空间
条件数
PCA
```

它们其实都围绕这一幅图：

```text
                    输入空间 R^n
                         │
             V^T：分解到 v_i 方向
                         │
                         ↓
          [c1, c2, ..., cr, ...]
                         │
                 Σ：分别乘 σ_i
                         │
      ┌──────────────────┴──────────────────┐
      │                                     │
   σ_i > 0                               σ_i = 0
有效信息方向                             零空间
      │                                     │
      ↓                                     ↓
σ_i c_i                                  直接消失
      │
      ↓
 U：组合到输出方向 u_i
      │
      ↓
                 输出空间 R^m
```

于是：

[
\boxed{
Av_i=\sigma_i u_i
}
]

是整个 SVD 世界最核心的公式。

进一步：

[
\boxed{
A
=

\sum_{i=1}^r
\sigma_i u_i v_i^T
}
]

告诉你：

> (A) 是一堆“输入方向 (v_i) → 输出方向 (u_i)”的秩 1 通道叠加。

伪逆则是：

[
\boxed{
A^+
===

\sum_{i=1}^r
\frac1{\sigma_i}v_i u_i^T
}
]

也就是把每个通道反过来。

而低秩近似：

[
\boxed{
A_k
===

\sum_{i=1}^k
\sigma_i u_i v_i^T
}
]

就是只保留最重要的 (k) 条通道。

所以可以最终压缩成一句：

[
\boxed{
\text{SVD 找通道，伪逆反通道，低秩近似删弱通道。}
}
]

而在你一直沿用的

[
\boxed{
T(v)\leftrightarrow Ax=b
}
]

主线中，它们的位置是：

[
\boxed{
\begin{array}{ccccc}
x
&
\xrightarrow{V^T}
&
\text{输入模式坐标}
&
\xrightarrow{\Sigma}
&
\text{输出模式坐标}
\
&&&&\downarrow U\
&&&&Ax
\end{array}
}
]

求解时反过来：

[
\boxed{
b
\xrightarrow{U^T}
\text{输出模式坐标}
\xrightarrow{\Sigma^+}
\text{反缩放}
\xrightarrow{V}
A^+b
}
]

压缩时则直接：

[
\boxed{
只保留最大的
\ \sigma_1,\ldots,\sigma_k
}
]

这三件事共同描述了：

> **一个线性变换中，信息从输入空间进入输出空间、如何被恢复，以及哪些信息其实最重要。**
