# S3 向量空间与子空间

> **学习定位**：本节属于第二层“空间层——有什么”。正文重点回答“哪些向量可以互相表示、存在多少个独立方向、这些方向形成什么空间”。涉及矩阵作用时只给必要的变换直觉，正式的线性变换理论留到第三层。

## 本节从什么问题产生

span 给出了许多“由线性组合自动形成的集合”。这些集合为什么可以稳定地做加法和数乘？什么样的集合才真正具有线性空间结构？

## 向量空间与子空间的基本结构

一个集合若对向量加法和标量乘法保持封闭，就具有线性结构。直观地说：

- 集合中的两个对象相加，结果仍在集合中。
- 集合中的对象乘任意标量，结果仍在集合中。
- 因而集合必然包含零向量。

在 $\mathbb R^3$ 中，下列集合是子空间：

$$
W=
\left\{
\begin{bmatrix}x\\y\\0\end{bmatrix}:x,y\in\mathbb R
\right\}
$$

它是经过原点的 $xy$ 平面。

下列集合不是子空间：

$$
S=
\left\{
\begin{bmatrix}x\\y\end{bmatrix}:x+y=1
\right\}
$$

因为零向量不满足 $x+y=1$。几何上，它是一条不经过原点的直线。

阶段 3 将进一步研究矩阵产生的列空间、行空间和零空间；此处只需建立“子空间必须保留线性运算”的直觉。

## 更统一的向量空间认识

向量空间是一个允许进行以下两种运算的对象集合：

1. 向量加法；
2. 标量乘法。

并且这些运算满足通常的线性运算规律。

最核心的直觉是：

> 向量空间对线性组合封闭。

也就是说，如果：

```text
u、v 属于 V
a、b 是标量
```

那么：

```text
a u + b v 仍然属于 V
```

这里的向量不一定是几何箭头，也可以是：

- 列向量；
- 矩阵；
- 多项式；
- 函数；
- 信号；
- 其他满足向量空间公理的对象。

例如，所有二维实数列向量组成一个向量空间：

```text
R² = {
      [x]
      [y]
      | x、y 是实数
     }
```

## 本节统一认识

子空间的关键不是“看起来像直线或平面”，而是对线性组合封闭。因此经过原点的直线/平面常常是子空间，而平移后的直线/平面通常不是。span 天然是子空间，因为对已有线性组合继续做线性组合仍留在原集合中。
