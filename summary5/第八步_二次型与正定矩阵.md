二次型可以先把它理解成一句话：

> **二次型就是：用一个矩阵去描述“空间中不同方向上的平方尺度”。**

它最核心的形式是：

```text
q(x) = x^T A x
```

它和你前面学的特征值、特征向量、对角化联系非常紧密。事实上，**理解二次型，最好的方式就是把它看成“对角化的一个重要应用”。**

---

# 一、先从几何意义理解二次型

先看二维最简单的情况。

设：

```text
x =
[x1
 x2]
```

考虑：

```text
q(x) = x1² + x2²
```

这其实就是向量长度的平方：

```text
q(x) = ||x||²
```

例如：

```text
x =
[3
 4]
```

那么：

```text
q(x) = 3² + 4² = 25
```

所以：

```text
q(x) = 常数
```

例如：

```text
x1² + x2² = 1
```

表示单位圆。

---

如果改成：

```text
q(x) = 4x1² + x2²
```

那么：

```text
4x1² + x2² = 1
```

表示一个椭圆。

为什么？

因为不同方向的“惩罚力度”不一样：

```text
x1 方向：乘 4
x2 方向：乘 1
```

因此：

```text
x1 稍微变大
→ q(x) 增长得很快

x2 变大
→ q(x) 增长得比较慢
```

所以二次型本质上是在描述：

```text
空间中不同方向
        ↓
有不同的平方缩放程度
```

这已经开始出现特征值的味道了。

---

# 二、为什么会出现 x^T A x

设：

```text
A =
[a  b
 c  d]
```

以及：

```text
x =
[x1
 x2]
```

首先：

```text
Ax =
[a x1 + b x2
 c x1 + d x2]
```

再左乘：

```text
x^T = [x1  x2]
```

于是：

```text
x^T A x
```

展开得到：

```text
= x1(a x1 + b x2)
  + x2(c x1 + d x2)
```

也就是：

```text
= a x1²
  + (b+c)x1x2
  + d x2²
```

所以一个二次型通常长成：

```text
q(x1,x2)
=
a x1²
+ b x1x2
+ c x2²
```

注意它的特点：

```text
每一项的总次数都是 2
```

例如：

```text
x1²
x1x2
x2²
```

都是二次项。

---

# 三、二次型不是一般的二次函数

比如：

```text
f(x1,x2)
=
3x1²
+ 2x1x2
+ 4x2²
```

这是二次型。

但是：

```text
f(x1,x2)
=
3x1²
+ 2x1x2
+ 4x2²
+ 5x1
+ 7
```

严格来说就不是纯粹的二次型了。

因为它还有：

```text
5x1    ← 一次项
7      ← 常数项
```

所以：

```text
二次型
=
纯二次部分
```

---

# 四、具体数值例子

考虑：

```text
A =
[2  1
 1  2]
```

取：

```text
x =
[x1
 x2]
```

那么：

```text
q(x) = x^T A x
```

先算：

```text
Ax =
[2x1 + x2
 x1 + 2x2]
```

再左乘：

```text
q(x)
=
[x1  x2]
[2x1 + x2
 x1 + 2x2]
```

得到：

```text
q(x)
=
x1(2x1+x2)
+
x2(x1+2x2)
```

展开：

```text
q(x)
=
2x1² + 2x1x2 + 2x2²
```

所以：

```text
A =
[2 1
 1 2]
```

编码的其实就是这个二次函数：

```text
2x1² + 2x1x2 + 2x2²
```

---

# 五、最关键的问题：x1x2 是什么意思？

如果二次型是：

```text
q(x) = 4x1² + x2²
```

很好理解：

```text
x1、x2 两个方向互不干扰
```

矩阵就是：

```text
A =
[4 0
 0 1]
```

已经是对角矩阵。

但是：

```text
q(x)
=
2x1² + 2x1x2 + 2x2²
```

里面出现：

```text
x1x2
```

这说明：

> 当前选择的 x1、x2 坐标轴，不是这个二次型真正“天然”的方向。

换句话说：

```text
矩阵有非对角元素
        ↓
坐标方向之间存在耦合
        ↓
图形通常发生旋转
```

这就直接把二次型和**特征向量、对角化**连起来了。

---

# 六、用特征向量寻找二次型真正的方向

继续看：

```text
A =
[2 1
 1 2]
```

它有两个特征向量方向：

```text
v1 =
[1
 1]

v2 =
[1
-1]
```

对应特征值：

```text
λ1 = 3
λ2 = 1
```

如果归一化：

```text
p1 =
1/√2 [1
      1]

p2 =
1/√2 [ 1
      -1]
```

组成：

```text
P = [p1 p2]
```

那么：

```text
P^T A P =
[3 0
 0 1]
```

也就是：

```text
A = P D P^T
```

其中：

```text
D =
[3 0
 0 1]
```

---

这时候，如果我们不再用原坐标：

```text
x =
[x1
 x2]
```

而改用特征向量坐标：

```text
y =
[y1
 y2]
```

满足：

```text
x = P y
```

那么原来的：

```text
q(x) = x^T A x
```

变成：

```text
q(x)
=
(Py)^T A (Py)
```

也就是：

```text
q(x)
=
y^T P^T A P y
```

由于：

```text
P^T A P = D
```

于是：

```text
q(x)
=
y^T D y
```

最终得到：

```text
q(x)
=
3y1² + y2²
```

注意发生了什么：

原来：

```text
2x1² + 2x1x2 + 2x2²
```

经过换基后：

```text
3y1² + y2²
```

**交叉项 y1y2 消失了。**

这正是对角化的几何意义。

---

# 七、所以二次型为什么和特征值关系这么密切？

因为对于实对称矩阵：

```text
A = A^T
```

一定可以正交对角化：

```text
A = P D P^T
```

其中：

```text
D =
[λ1           0
    λ2
       ...
           λn]
```

于是：

```text
q(x) = x^T A x
```

经过：

```text
x = Py
```

变成：

```text
q(x)
=
λ1 y1²
+ λ2 y2²
+ ...
+ λn yn²
```

这句话非常重要。

它告诉我们：

```text
特征向量
=
二次型真正的主轴方向

特征值
=
沿着这些方向的平方缩放系数
```

所以你可以把：

```text
x^T A x
```

理解成：

```text
先把 x 分解到 A 的特征向量方向
            ↓
每个方向分别平方
            ↓
乘对应 λ
            ↓
全部加起来
```

即：

```text
x = c1v1 + c2v2 + ... + cnvn
```

那么：

```text
q(x)
=
λ1 c1²
+ λ2 c2²
+ ...
+ λn cn²
```

---

# 八、特征值的正负决定二次型的形状

这一点非常重要。

假设对角化以后：

```text
q(x)
=
λ1 y1² + λ2 y2²
```

## 情况 1：所有 λ > 0

例如：

```text
q(x) = 3y1² + y2²
```

无论 y 指向哪里：

```text
q(x) > 0
```

只要：

```text
x != 0
```

这种称为：

```text
正定二次型
```

对应：

```text
A 正定
```

几何上是一个“碗”：

```text
        ↑
      ╱   ╲
    ╱       ╲
──●────────────
```

或者看等高线：

```text
椭圆
```

---

## 情况 2：所有 λ < 0

例如：

```text
q(x)
=
-3y1² - y2²
```

称为：

```text
负定
```

相当于一个倒扣的碗。

---

## 情况 3：有正有负

例如：

```text
q(x)
=
3y1² - y2²
```

一个方向往上：

```text
+3y1²
```

一个方向往下：

```text
-y2²
```

所以形成：

```text
马鞍面
```

称为：

```text
不定二次型
```

这也是为什么优化问题里 Hessian 的特征值这么重要。

---

# 九、为什么 A 一般只需要看对称矩阵？

这里有一个非常漂亮的性质。

假设 A 不对称，也可以写：

```text
A =
(A + A^T)/2
+
(A - A^T)/2
```

分别叫：

```text
对称部分
+
反对称部分
```

记：

```text
S = (A + A^T)/2
K = (A - A^T)/2
```

那么：

```text
x^T A x
=
x^T S x
+
x^T K x
```

但反对称矩阵满足：

```text
x^T K x = 0
```

所以：

```text
x^T A x
=
x^T S x
```

也就是说：

> **一个二次型实际上只关心矩阵 A 的对称部分。**

因此研究二次型时，通常默认：

```text
A = A^T
```

这也是为什么二次型会天然进入：

```text
实对称矩阵
→ 正交特征向量
→ 正交对角化
→ 特征值
```

这条主线。

---

# 十、从 T(x) = Ax 的角度重新理解

你现在的主线是：

```text
T(x) <-> Ax
```

以前我们研究：

```text
Ax
```

关注的是：

```text
输入一个向量 x
↓
A 对它进行线性变换
↓
得到另一个向量 Ax
```

而二次型：

```text
x^T A x
```

多了一步：

```text
x
↓
A
↓
Ax
↓
和原来的 x 做内积
↓
x^T A x
```

所以：

```text
Ax       → 输出一个向量

x^T A x  → 输出一个标量
```

可以理解成：

```text
q(x)
=
<x, Ax>
```

如果 A 是对称矩阵，那么这个数在衡量：

> **A 在 x 这个方向上到底“作用了多强”。**

特别是单位向量：

```text
||x|| = 1
```

时：

```text
x^T A x
```

叫做 Rayleigh quotient 的核心形式。

沿特征向量：

```text
x = vi
```

就有：

```text
vi^T A vi
=
vi^T λi vi
```

如果：

```text
||vi|| = 1
```

那么：

```text
vi^T A vi = λi
```

所以：

> **特征值就是二次型沿特征向量方向上的数值。**

---

# 十一、这和你刚学的 P、P⁻¹ 有什么联系？

你刚刚在研究：

```text
P⁻¹ x
```

为什么能把 x 转换成特征向量基下的坐标。

对于一般对角化：

```text
A = P D P⁻¹
```

其中：

```text
P⁻¹x
```

就是把：

```text
标准基坐标
```

转换成：

```text
特征向量基坐标
```

而二次型里，因为 A 是实对称矩阵，特征向量可以取成标准正交基，所以：

```text
P⁻¹ = P^T
```

因此：

```text
y = P^T x
```

就是：

```text
把 x 投影到每一个特征向量方向
```

于是：

```text
q(x)
=
x^T A x
=
y^T D y
=
Σ λi yi²
```

整个逻辑就完全连起来了。

---

# 十二、和 SVD 的关系

对于对称正定矩阵：

```text
A = P D P^T
```

而 SVD 是：

```text
A = U Σ V^T
```

对称正定情况下：

```text
U = V = P
```

并且：

```text
σi = λi
```

于是：

```text
A = P D P^T
```

实际上就是 SVD 的特殊形式。

因此：

```text
二次型
    ↓
对称矩阵
    ↓
特征值分解
    ↓
主轴方向
    ↓
椭圆 / 椭球
    ↓
SVD
```

这些不是零散知识，而是一整条主线。

---

# 十三、最终心智模型

把二次型记成下面这张图：

```text
                    x
                    │
                    ▼
                 Ax
                    │
                    ▼
               <x, Ax>
                    │
                    ▼
              x^T A x
                    │
                    ▼
                 二次型
                    │
          ┌─────────┴─────────┐
          ▼                   ▼
       几何意义              代数意义
          │                   │
       椭圆/椭球           二次表达式
       马鞍面             x^T A x
          │                   │
          └─────────┬─────────┘
                    ▼
              A 是对称矩阵
                    │
                    ▼
              特征值分解
                    │
              A = P D P^T
                    │
          ┌─────────┴─────────┐
          ▼                   ▼
     P：特征向量           D：特征值
     主轴方向             各方向尺度
          │                   │
          └─────────┬─────────┘
                    ▼
              y = P^T x
                    │
                    ▼
       q(x) = Σ λi yi²
```

所以最值得记住的是：

```text
二次型 q(x) = x^T A x

本质：
A 给空间中的不同方向赋予不同的“平方权重”。

特征向量：
找到这些真正独立的主方向。

特征值：
告诉你每个主方向上的权重。

对角化：
把混合的二次型，
变成互不干扰的平方项之和。
```

这也是为什么**二次型最好紧接着“特征值 → 特征向量 → 对角化”学习**：它几乎就是这套知识第一次真正体现出几何威力的地方。
