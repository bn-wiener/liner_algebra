# 向量空间、基、坐标、矩阵与线性变换：统一总结

## 0. 核心主线

这一组问题可以统一为：

向量空间 → 选择基 → 坐标表示 → 线性组合 → 矩阵 → 线性变换

最核心的关系是：

```text
输出向量的坐标 = 线性变换矩阵 × 输入向量的坐标
```

也可以写成：

```text
[T(v)]_C = A [v]_B
```

其中：

- `v` 是输入空间中的向量；
- `B` 是输入空间的一组有序基；
- `C` 是输出空间的一组有序基；
- `[v]_B` 是输入向量在输入基 `B` 下的坐标；
- `A` 是线性变换在输入基 `B` 和输出基 `C` 下的矩阵；
- `[T(v)]_C` 是输出向量在输出基 `C` 下的坐标。

---

# 1. 什么是向量空间

向量空间是一个允许进行以下两种运算的对象集合：

1. 向量加法；
2. 标量乘法。

并且这些运算满足通常的线性运算规律。

最核心的直觉是：

> 向量空间对线性组合封闭。

也就是说，如果：

```text
u、v 属于 V
a、b 是标量
```

那么：

```text
a u + b v 仍然属于 V
```

这里的向量不一定是几何箭头，也可以是：

- 列向量；
- 矩阵；
- 多项式；
- 函数；
- 信号；
- 其他满足向量空间公理的对象。

例如，所有二维实数列向量组成一个向量空间：

```text
R² = {
      [x]
      [y]
      | x、y 是实数
     }
```

---

# 2. 什么是基

设 `V` 是一个向量空间。

一组向量：

```text
B = (b1, b2, ..., bn)
```

称为 `V` 的一组基，需要同时满足两个条件。

## 2.1 张成整个空间

```text
span(b1, b2, ..., bn) = V
```

这保证任意向量 `v` 都可以写成：

```text
v = x1 b1 + x2 b2 + ... + xn bn
```

## 2.2 线性无关

如果：

```text
c1 b1 + c2 b2 + ... + cn bn = 0
```

只能推出：

```text
c1 = c2 = ... = cn = 0
```

那么这些向量线性无关。

线性无关保证向量的表示是唯一的。

因此：

```text
基 = 线性无关 + 张成整个空间
```

也可以把基理解为：

> 一组最少但足够的生成向量。

- “足够”对应张成整个空间；
- “最少、无冗余”对应线性无关。

---

# 3. 向量与坐标的区别

若：

```text
B = (b1, b2, ..., bn)
```

是向量空间 `V` 的一组有序基，并且：

```text
v = x1 b1 + x2 b2 + ... + xn bn
```

那么由这些系数组成的列向量：

```text
[v]_B =
[x1]
[x2]
[...]
[xn]
```

称为向量 `v` 在基 `B` 下的坐标。

必须区分：

```text
向量 v ≠ 向量 v 在基 B 下的坐标 [v]_B
```

- `v` 是空间中的对象；
- `[v]_B` 是该对象相对于基 `B` 的数值描述。

同一个向量在不同基下通常具有不同坐标。

因此：

> 坐标永远是相对于某组有序基而言的。

---

# 4. 任意线性组合的系数是否都是坐标

设：

```text
v = a1 u1 + a2 u2 + ... + ak uk
```

这里的 `a1、a2、...、ak` 首先只是线性组合系数。

只有当：

```text
(u1, u2, ..., uk)
```

是所讨论空间或子空间的一组有序基时，这些系数才是坐标。

具体来说：

- 如果 `u1、...、uk` 是整个空间的基，系数是该空间中的坐标；
- 如果它们只是某个子空间的基，系数是该子空间中的坐标；
- 如果它们线性相关，表示可能不唯一，此时只能称为组合系数；
- 如果它们不能张成目标向量，则目标向量无法由它们表示。

---

# 5. 基生成三个向量，再由三个向量生成新向量

设向量空间 `V` 的一组基为：

```text
B = (b1, b2, ..., bn)
```

三个向量 `u1、u2、u3` 都属于 `V`，因此都可以由这组基表示：

```text
u1 = a11 b1 + a21 b2 + ... + an1 bn
u2 = a12 b1 + a22 b2 + ... + an2 bn
u3 = a13 b1 + a23 b2 + ... + an3 bn
```

再用它们生成新向量：

```text
v = x1 u1 + x2 u2 + x3 u3
```

把 `u1、u2、u3` 的表达式代入后，`v` 仍然可以写成原基的线性组合：

```text
v =
(a11 x1 + a12 x2 + a13 x3) b1
+
(a21 x1 + a22 x2 + a23 x3) b2
+
...
+
(an1 x1 + an2 x2 + an3 x3) bn
```

所以：

> 线性组合的线性组合，仍然是原基的线性组合。

中间向量 `u1、u2、u3` 只是生成 `v` 的中间层，并没有脱离原空间和原基。

---

# 6. 把三个向量写成矩阵

若 `u1、u2、u3` 都是二维向量：

```text
u1、u2、u3 属于 R²
```

可以把它们按列排列：

```text
A = [u1  u2  u3]
```

例如：

```text
u1 = [a1]    u2 = [b1]    u3 = [c1]
     [a2]         [b2]         [c2]
```

那么：

```text
A = [a1  b1  c1]
    [a2  b2  c2]
```

矩阵 `A` 有两行三列，所以它是一个 `2 × 3` 矩阵。

设：

```text
x =
[x1]
[x2]
[x3]
```

那么：

```text
A x = x1 u1 + x2 u2 + x3 u3
```

因此：

> 矩阵乘向量，本质上就是用输入向量的分量，对矩阵的各列进行线性组合。

---

# 7. 为什么这是从三维到二维的线性变换

输入是三个系数组成的向量：

```text
x =
[x1]
[x2]
[x3]
```

所以输入属于三维空间 `R³`。

输出是：

```text
A x = x1 u1 + x2 u2 + x3 u3
```

由于 `u1、u2、u3` 都是二维向量，所以输出属于二维空间 `R²`。

因此矩阵 `A` 定义了线性变换：

```text
T: R³ → R²
T(x) = A x
```

这里：

- 输入空间是三维系数空间；
- 输出空间是二维向量空间；
- 三个输入分量分别控制三个二维列向量的组合权重。

所以同一个式子可以从两个角度理解。

## 从输出角度看

```text
x1 u1 + x2 u2 + x3 u3
```

是三个二维向量的线性组合。

## 从输入到输出角度看

```text
A: R³ → R²
```

是从三维系数空间到二维向量空间的线性变换。

这两种说法描述的是同一个过程。

---

# 8. 矩阵的列为什么是输入基向量的变换结果

三维输入空间 `R³` 的标准基为：

```text
e1 = [1]    e2 = [0]    e3 = [0]
     [0]         [1]         [0]
     [0]         [0]         [1]
```

对于：

```text
A = [u1  u2  u3]
```

有：

```text
A e1 = u1
A e2 = u2
A e3 = u3
```

如果定义：

```text
T(x) = A x
```

那么：

```text
T(e1) = u1
T(e2) = u2
T(e3) = u3
```

所以：

> 矩阵的第 j 列，就是第 j 个输入基向量经过线性变换后的结果。

更严格地说，矩阵的第 `j` 列，是 `T(ej)` 在输出基下的坐标列。

---

# 9. 同时存在输入基和输出基

对于：

```text
T: R³ → R²
```

存在两套不同的基。

## 9.1 输入空间的基

输入空间 `R³` 的标准基为：

```text
e1、e2、e3
```

矩阵有三列，是因为输入空间有三个基方向。

每一列回答：

> 对应的输入基向量经过变换后被送到了哪里？

## 9.2 输出空间的基

输出空间 `R²` 的标准基为：

```text
f1 = [1]    f2 = [0]
     [0]         [1]
```

每个 `uj` 都可以写成：

```text
uj = a1j f1 + a2j f2
```

矩阵第 `j` 列中的两个数，就是输出向量 `uj` 在二维输出基下的坐标。

因此矩阵元素 `aij` 的含义是：

> 第 j 个输入基向量经过变换后，在第 i 个输出基方向上的分量。

可以这样记：

- 列编号对应输入基方向；
- 行编号对应输出基方向。

---

# 10. 输入坐标与输出线性组合系数是同一组数

任意三维输入向量都可以写成：

```text
x = x1 e1 + x2 e2 + x3 e3
```

经过线性变换：

```text
T(x)
= T(x1 e1 + x2 e2 + x3 e3)
= x1 T(e1) + x2 T(e2) + x3 T(e3)
= x1 u1 + x2 u2 + x3 u3
```

因此，同一组数 `x1、x2、x3` 有双重身份：

1. 它们是输入向量 `x` 在三维输入基下的坐标；
2. 它们是输出向量中组合 `u1、u2、u3` 的系数。

这不是巧合，而是由线性性决定的。

线性变换保持组合系数不变，只把输入基向量替换成它们的像：

```text
x1 e1 + x2 e2 + x3 e3
            ↓ T
x1 u1 + x2 u2 + x3 u3
```

---

# 11. 对最终表述的精确整理

可以这样说：

> 对输出空间而言，`x1、x2、x3` 是组合 `u1、u2、u3` 的线性组合系数。

同时：

> 对整个输入到输出的关系而言，`[u1 u2 u3]` 是一个线性变换矩阵。

完整写法是：

```text
A = [u1  u2  u3]

x =
[x1]
[x2]
[x3]

A x = x1 u1 + x2 u2 + x3 u3 = v
```

矩阵 `A` 表示：

```text
T: R³ → R²
```

而输入向量 `x` 既是三维输入向量，也是组合矩阵三列的系数向量。

---

# 12. 一个完整例子

取三个二维向量：

```text
u1 = [1]    u2 = [0]    u3 = [1]
     [0]         [1]         [1]
```

组成矩阵：

```text
A = [1  0  1]
    [0  1  1]
```

它定义线性变换：

```text
T: R³ → R²
```

输入标准基满足：

```text
T(e1) = u1
T(e2) = u2
T(e3) = u3
```

取输入：

```text
x =
[2]
[3]
[4]
```

则：

```text
A x = 2 u1 + 3 u2 + 4 u3
```

计算：

```text
2 u1 = [2]
       [0]

3 u2 = [0]
       [3]

4 u3 = [4]
       [4]
```

相加得到：

```text
A x =
[6]
[7]
```

因此：

```text
[2]       [6]
[3]  →    [7]
[4]
```

从输入角度：

```text
x = 2 e1 + 3 e2 + 4 e3
```

从输出角度：

```text
A x = 2 u1 + 3 u2 + 4 u3
```

---

# 13. 为什么三维到二维一定存在信息丢失

对于一个 `2 × 3` 矩阵，输入有三个自由分量，输出最多只有两个独立方向。

因此一定存在某个非零三维向量 `z`，满足：

```text
A z = 0
```

也就是说，不同的三维输入可能产生相同的二维输出：

```text
A(x + z) = A x
```

在上面的例子中：

```text
u3 = u1 + u2
```

因此：

```text
u1 + u2 - u3 = 0
```

也就是：

```text
A
[ 1]
[ 1]
[-1]
=
[0]
[0]
```

这说明输入空间中有一个方向被矩阵压缩成了零。

---

# 14. 列空间的意义

矩阵所有可能的输出构成：

```text
Col(A) = span(u1, u2, u3)
```

也就是说，矩阵的列决定输出能够覆盖哪些方向。

对于一个 `2 × 3` 矩阵：

- 如果列空间是二维的，输出能够覆盖整个 `R²`；
- 如果列空间是一维的，输出只能落在一条直线上；
- 如果所有列都是零向量，所有输出都是零向量。

# 15. 最容易混淆的几组概念

## 15.1 向量与坐标

```text
向量 v ≠ 向量 v 在某组基下的坐标
```

向量是对象，坐标是相对于基的数值描述。

## 15.2 矩阵列与输入基向量

对于：

```text
A: R³ → R²
```

- 输入基向量 `e1、e2、e3` 是三维向量；
- 矩阵列 `u1、u2、u3` 是二维向量；
- `uj = A ej`。

不能说矩阵的列本身是三维向量。

## 15.3 线性组合与线性变换

```text
x1 u1 + x2 u2 + x3 u3
```

从输出角度是线性组合。

```text
x → A x
```

从整体角度是线性变换。

它们是同一个运算的两种观察方式。

## 15.4 任意列向量组与基

`u1、u2、u3` 可以组成矩阵，但不一定构成输出空间的一组基。

在二维空间中，三个向量必然线性相关，因此不可能同时构成 `R²` 的基。

## 15.5 线性变换与换基

线性变换改变对象：

```text
v → T(v)
```

换基不改变对象，只改变坐标描述：

```text
[v]_B ↔ [v]_C
```

二者都可以用矩阵表示，但含义不同。

---

# 16. 一般形式

设：

```text
A = [u1  u2  ...  un]
```

是一个 `m × n` 矩阵。

它定义线性变换：

```text
T: Rⁿ → Rᵐ
```

输入标准基为：

```text
e1、e2、...、en
```

矩阵列满足：

```text
T(ej) = uj
```

对任意输入：

```text
x =
[x1]
[x2]
[...]
[xn]
```

都有：

```text
A x = x1 u1 + x2 u2 + ... + xn un
```

因此：

```text
矩阵列数 = 输入空间维数
```

```text
每列的分量数 = 输出空间维数
```

---

# 17. 最终统一结论

整个讨论可以浓缩成以下内容：

1. 向量空间是对线性组合封闭的对象集合。
2. 基是一组线性无关且能张成整个空间的向量。
3. 向量相对于基的唯一表示系数称为坐标。
4. 线性组合的线性组合最终仍然是原基的线性组合。
5. 把若干输出向量按列排列，就得到一个矩阵。
6. 矩阵乘向量等于用输入分量对矩阵列做线性组合。
7. 一个 `m × n` 矩阵表示从 `Rⁿ` 到 `Rᵐ` 的线性变换。
8. 矩阵第 `j` 列是第 `j` 个输入基向量的像。
9. 输入向量的坐标，同时也是组合矩阵各列的系数。
10. “列向量线性组合”和“线性变换”不是两个不同事实，而是同一个线性结构的两种表述。

最终可以统一写成：

```text
x = x1 e1 + x2 e2 + ... + xn en
```

```text
T(ej) = uj
```

```text
T(x)
= x1 u1 + x2 u2 + ... + xn un
= A x
```

其中：

```text
A = [u1  u2  ...  un]
```

这就是向量空间、基、坐标、线性组合、矩阵和线性变换之间最核心的统一关系。
