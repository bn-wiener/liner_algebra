# 基础层知识地图

$$
\text{向量}
\rightarrow\text{矩阵}
\rightarrow A\boldsymbol{x}
\rightarrow A\boldsymbol{x}=\boldsymbol{b}
\rightarrow [A\mid\boldsymbol{b}]
\rightarrow\text{行变换}
\rightarrow\text{REF/RREF}
\rightarrow\text{主元/自由变量}
\rightarrow\text{存在性/唯一性}
\rightarrow A\boldsymbol{x}=\boldsymbol{0}
\rightarrow\boldsymbol{x}_p+\boldsymbol{x}_h
\rightarrow\text{参数向量形式}
$$

|---|---|
| B1 | 一个线性对象怎样表示？ |
| B2 | 多组线性信息怎样组织？ |
| B3 | 矩阵乘向量究竟在算什么？ |
| B4 | 方程组怎样写成统一形式？ |
| B5 | 怎样改写方程而不改变解？ |
| B6 | 怎样系统消元？ |
| B7 | 哪些变量被决定、哪些可以自由变化？ |
| B8 | 有没有解？若有，是否唯一？ |
| B9 | 哪些输入变化会得到零输出？ |
| B10 | 为什么全部解具有统一结构？ |
| B11 | 怎样把整族解清楚地写出来？ |
