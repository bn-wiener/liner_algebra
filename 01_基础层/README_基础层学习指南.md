# 第一层：基础层——会表示、会计算

> **基础层的任务：会表示、会计算。** 本层始终围绕 $A\boldsymbol{x}=\boldsymbol{b}$ 展开。允许提前看到“空间”和“变换”的影子，但正式的空间定义与变换理论留到后两层。当前目标是：看到一个线性问题，能够把它表示出来、算出来，并读懂计算结果。

## 1. 学习主线

第一层不是 11 个孤立知识点，而是一条连续链：

$$
\text{向量}
\rightarrow
\text{矩阵}
\rightarrow
A\boldsymbol{x}
\rightarrow
A\boldsymbol{x}=\boldsymbol{b}
\rightarrow
[A\mid\boldsymbol{b}]
\rightarrow
\text{高斯消元}
\rightarrow
\text{主元/自由变量}
\rightarrow
\text{解的三种情况}
\rightarrow
A\boldsymbol{x}=\boldsymbol{0}
\rightarrow
\text{特解+齐次解}
\rightarrow
\text{参数向量形式}
$$

学习过程中始终追问：当前对象怎样表示？当前运算在算什么？结果怎样读？这个结果为什么会自然引出后面的“空间”？
